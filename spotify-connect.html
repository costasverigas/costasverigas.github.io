Σύνδεση της playlist

Αυτή η σύνδεση επιτρέπει στο repository να διαβάζει την playlist και να ανανεώνει τα εξώφυλλα. Δεν αλλάζει τη μουσική ή τον λογαριασμό σου.

  1. Στο Spotify Developer Dashboard, δημιούργησε μια εφαρμογή για το portfolio, επιλέγοντας Web API.
  2. Στα Redirect URIs πρόσθεσε ακριβώς τη διεύθυνση παρακάτω και αποθήκευσε.
  3. Αντέγραψε το Client ID της εφαρμογής στο πεδίο και σύνδεσε τον λογαριασμό που έχει την playlist.

Η σύνδεση ολοκληρώθηκε

Στα GitHub Actions secrets πρόσθεσε τα δύο παρακάτω. Το token εμφανίζεται μόνο εδώ, στον browser σου. Μην το στείλεις σε μήνυμα ή το βάλεις σε αρχείο του repository.

Μετά, άνοιξε GitHub → Actions, επίλεξε Refresh Spotify portfolio και πάτησε Run workflow. Από εκεί και πέρα ο έλεγχος γίνεται κάθε 6 ώρες.

Η Spotify ορίζει διάρκεια 6 μηνών για τα refresh tokens. Όταν λήξει, επανάλαβε τη σύνδεση και αντικατάστησε το SPOTIFY_REFRESH_TOKEN.
